Lazy Fishing

Background

I put this together to play around with making some really small pixel art. I wanted a pretty cozy game that had a beautiful background and simple mechanics. The main concept of the fishing part was lifted from Stardew Valley's fishing, but this is simplified with no additional rods or fishing spots. The fish that bite are randomized and have different sizes and rarities. My focus in building this game was to architect it in a scaleable way. I made pretty heavy use of Godot's Resources and Class Inheritance to make adding additional content pretty easy when I make the assets.It was pretty fun to put together and I think it's fun to play as well!

Ideas for additional features

I'd like to add some complexity to the bite mechanic. Right now the fish will bite forever and you just need to click (or press space) to start the "game" portion.

I'd also like to add a bunch more fish. I have code in place to implement a chance for a legendary fish as well, but I haven't had the time to make the sprites and add them in.
